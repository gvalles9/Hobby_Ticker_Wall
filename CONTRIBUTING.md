# Contributing to Hobby Ticker

Hobby Ticker is a fork of [Colin Waddell's FlightTracker](https://github.com/ColinWaddell/FlightTracker). Contributions to this repository should target Hobby Ticker-specific changes; upstream contributions should be made in the original repository.

## Issues and pull requests

Report bugs and propose changes using the GitHub issue and pull-request tools for the repository where you found the problem. Include your Hobby Ticker version, hardware details, steps to reproduce, and relevant logs. Do not post passwords, API keys, or an unredacted configuration file.

Pull requests should be focused, explain the behavior being changed, and include tests for changed behavior where practical. Review generated or AI-assisted code carefully before submitting it.

## Upstream changes

When adapting upstream changes, preserve the original project's license and attribution notices. The updater included in this fork points at the original FlightTracker releases; installing one of those releases will replace fork-specific changes.
